# Projeto Spotify Clone - Graduação em Ciência da Computação

Este repositório contém o código desenvolvido para um trabalho acadêmico da graduação em Ciência da Computação, focado na criação de uma aplicação que simula funcionalidades básicas do Spotify.

## 🚀 Visão Geral do Projeto

O objetivo principal foi construir um sistema de gerenciamento de músicas e playlists, utilizando **Python** para a lógica de programação e **JSON** para o armazenamento de dados. O projeto visa demonstrar a aplicação de conceitos de programação orientada a objetos, manipulação de dados e interação com o usuário em um cenário prático e familiar.

## ✨ Funcionalidades

O aplicativo permite ao usuário realizar as seguintes operações:

* **Autenticação:** Criar uma nova conta de usuário.
* **Gestão de Músicas:**
    * Adicionar músicas à sua biblioteca pessoal.
    * Remover músicas da sua biblioteca.
    * Curtir e descurtir músicas.
* **Gestão de Playlists:**
    * Criar novas playlists.
    * Remover playlists existentes.
    * Atribuir um nome para cada playlist.
    * Visualizar a quantidade e quais músicas estão em uma playlist específica.

## 🛠️ Tecnologias Utilizadas

* **Python:** Linguagem de programação principal.
* **JSON:** Formato de arquivo para armazenamento de dados (músicas, usuários, playlists).

## ▶️ Como Executar o Projeto

Para rodar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git](https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git)
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd SEU_REPOSITORIO
    ```
3.  **Execute o arquivo principal:**
    ```bash
    python seu_arquivo_principal.py 
    ```
    *(Substitua `seu_arquivo_principal.py` pelo nome do seu arquivo Python que inicia a aplicação, por exemplo `main.py` ou `app.py`.)*
